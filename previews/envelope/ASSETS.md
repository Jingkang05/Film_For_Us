# Botanical envelope assets

Created with the built-in ImageGen tool on 2026-11-07, using the user's supplied botanical stationery image as a material reference. These are newly generated component assets, not crops of the full reference layout, stock downloads or placeholder icons. The background, envelope folds, printed title, stamp, paper insert, flower shadows, and interaction remain independent HTML/CSS layers.

The generated PNGs were resized and encoded with the project's existing Sharp dependency. Alpha was preserved at alphaQuality 100; no white matte was added. The CSS shadow masks use the actual flower asset's transparency. The source PNGs remain in the local generation library; the website uses only the workspace WebP files below.
