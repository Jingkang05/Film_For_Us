# Isolated frontend review

The previous Preview returned HTML for `/create`, but both `/api/auth/session` and `/api/platform` failed with HTTP 500. Preview has no Supabase URL, publishable key, database URL, encryption key, or isolated R2 configuration. The inherited Blob token is deliberately rejected by `openStorage` in Preview. Eager storage initialization caused the function to fail before returning an API response. Routing and the account guard were behaving as implemented; authentication was not bypassed to resolve this.

For frontend review only, builds targeting **Preview AND `codex/phase-4-supabase-multi-user`** install a browser-memory API substitute using the existing public sample photographs and actual UI components. The server function checks the same condition before importing/opening any storage and returns 503 for every API request. It never opens Supabase, R2 or Blob, including for direct API calls. Production builds use the ordinary entry point and retain all existing authentication and authorization. Other Preview branches are not opted in. Remove this branch-specific demonstration before a real hosted integration review.

Routes: `/login`, `/create`, `/dashboard`, `/editor/DEMO000000000001`, `/a/ui-sample?sidebar=1`. Login uses any sample email and synthetic code `12345678`; no email is sent. Other interfaces can be opened directly without signing in because they are static demonstrations, not accounts. Save/publication changes exist only in the current document. Reload/navigation reseeds the sample; uploads and deletion are disabled. Local/session storage are replaced by document-memory implementations to avoid persisting likes or demo state. A fixed navigation notice explains these limits.

Verification: `pnpm check`, `pnpm test`, the existing Phase 4 browser suite, then build the demo entry with the two environment variables above and run `node scripts/check-ui-preview.mjs`. The latter checks all five interfaces on desktop and 390px mobile, demo login, Create, Save, state reset, rejection of unknown/private album requests and external requests, and the direct server 503. Browser API and external network request counts must both be zero. Screenshots are private ignored artifacts under `.data/ui-preview-qa/`.
